# 基于逻辑回归的个人信贷违约预测与信用评分卡构建

## 1. 项目简介

本项目基于 Kaggle Give Me Some Credit 数据集，使用 Python 和机器学习方法构建个人信贷违约预测模型，并进一步设计信用评分卡。

项目主要目标是根据客户的历史信用信息，预测客户未来两年发生严重逾期的概率，并将预测概率转换为直观的信用评分，从而辅助评估客户的信用风险。

## 2. 使用技术

建模方法：Logistic Regression（逻辑回归）

## 3. 项目主要流程

### 3.1 数据预处理

- 使用 Pandas 进行数据读取和探索性分析。
- 检查缺失值及异常值。
- 对缺失值进行处理。
- 将数据划分为训练集和测试集。
- 使用训练集确定缺失值填充规则，避免数据泄露。

### 3.2 特征分箱与编码

- 使用卡方分箱方法（Chi-square Binning）对特征进行分箱。
- 计算各分箱的 WOE 值。
- 计算特征的 IV 值，并进行特征筛选。
- 对特征进行相关性分析。
- 使用训练集学习 WOE 转换规则，并将相同规则应用于测试集。

### 3.3 逻辑回归模型构建

- 使用 WOE 转换后的特征训练 Logistic Regression 模型。
- 使用模型预测客户违约概率。
- 通过 ROC 曲线、AUC、KS、混淆矩阵、Precision、Recall 和 F1-score 等指标评估模型。

### 3.4 信用评分卡构建

- 根据逻辑回归模型的系数和截距计算基础分。
- 使用 PDO（Points to Double the Odds）参数进行信用评分转换。
- 计算各个特征不同分箱对应的分值。
- 构建完整信用评分卡。
- 实现新客户的信用评分与风险等级判断。

### 3.5 模型稳定性分析

使用 PSI（Population Stability Index）比较训练集和测试集的评分分布，分析模型在本次数据划分下的评分分布稳定性。

## 4. 模型评估结果

模型在测试集上的主要结果如下：

| 评估指标 | 结果 |
|---|---:|
| AUC | 0.8568 |
| KS | 0.5617 |
| Accuracy | 93.73% |
| Precision | 60.11% |
| Recall | 18.28% |
| F1-score | 28.04% |

此外，训练集与测试集评分分布的 PSI 为 0.000107，
说明本次随机划分下两组评分分布较为接近。
该结果不代表模型在长期业务环境下具有稳定性。

注：上述分类指标对应分类阈值 0.5。由于数据存在类别不平衡问题，Accuracy 较高并不代表模型能够识别大部分违约客户，模型仍需要结合业务需求进一步调整分类阈值。

## 5. 信用评分卡

本项目采用以下评分转换公式：

$$
Score=600+\frac{50}{\ln 2}\ln\left(\frac{1-p}{p}\right)
$$

其中：

- \(p\)：模型预测的违约概率。
- 基准分（Base Score）：600。
- PDO：50。

通过逻辑回归模型的系数和截距，将总评分拆分为基础分和各特征分箱分值。

对于新客户，输入原始特征后，依次进行分箱、WOE 转换和分箱分值查询，最终得到客户信用评分。

此外，通过比较模型概率转换评分与评分卡分值累加结果，验证两种评分方式的一致性。
